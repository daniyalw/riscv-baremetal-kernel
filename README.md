# RISC-V Runtime Kernel

## Goal

A minimal interrupt-driven RISC-V kernel built in QEMU with an embedded-inspired architecture.

## Planned Features

- UART logging
- Interrupt handling
- Timer subsystem
- Cooperative scheduler
- Interactive shell
